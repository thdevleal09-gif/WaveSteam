# WaveSteam 🎵

O **WaveSteam** é um projeto simples desenvolvido em C# para praticar os fundamentos da Programação Orientada a Objetos (POO). A ideia surgiu da vontade de organizar algumas músicas de um dos artistas que mais escuto e, ao mesmo tempo, colocar em prática o que venho aprendendo na programação.

## ✨ Funcionalidades

- Cadastro de músicas com nome, artista, duração e disponibilidade.
- Organização de músicas em álbuns.
- Associação de álbuns a um artista.
- Exibição da discografia e da duração total de cada álbum.
- Exibição da ficha técnica de cada música.

## 🧠 Conceitos praticados

- **Classes e objetos**
- **Construtores e propriedades**
- **Encapsulamento**
- **Composição e relacionamento entre objetos**
- **Coleções com `List<T>`**
- **LINQ** para calcular a duração total das músicas de um álbum

## 🛠️ Tecnologias

- C#
- .NET 10

## ▶️ Como executar

1. Tenha o [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) instalado.
2. Clone este repositório:

   ```bash
   git clone https://github.com/thdevleal09-gif/WaveSteam.git
   ```

3. Entre na pasta do projeto:

   ```bash
   cd WaveSteam
   ```

4. Execute a aplicação:

   ```bash
   dotnet run
   ```
